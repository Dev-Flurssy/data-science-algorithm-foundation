GRAPHS
A graph is a collection of vertices (nodes) connected by edges that represent relationships between objects.

------------------------------------------------------------
WHY GRAPHS ARE NEEDED

Graphs help represent complex relationships between objects efficiently.

Examples:
• Social Networks
• Road Maps
• Computer Networks
• Project Dependencies

Problem: Arrays and linked lists cannot easily represent many-to-many relationships.
Solution: Graphs provide a flexible structure for interconnected data.

------------------------------------------------------------
UNDIRECTED GRAPH

An undirected graph has edges with no direction.

Example:
A ----- B

Meaning:
A is connected to B
B is connected to A

Properties:
• Order of vertices does not matter.
• Edges are drawn as lines.
• Relationships are two-way.

------------------------------------------------------------
DIRECTED GRAPH (DIGRAPH)

A directed graph has edges with a specific direction.

Example:
A → B

Meaning:
A can reach B
B cannot necessarily reach A

Properties:
• Order of vertices matters.
• Edges are represented using arrows.
• Relationships are one-way.

------------------------------------------------------------
SIMPLE PATH

A path is a sequence of connected vertices from one vertex to another.

Example:
1 → 2 → 4 → 5

Properties:
• Consecutive vertices must be connected.
• Intermediate vertices are distinct.
• Used to determine reachability.

------------------------------------------------------------
VERTEX-LABELED GRAPH

A vertex-labeled graph stores additional data inside its vertices.

Example:
Vertex    Data
1         A
2         B
3         C

Representation: V = {(1,A), (2,B), (3,C)}
Purpose: Store extra information with each node.

------------------------------------------------------------
CYCLIC GRAPH

A cyclic graph contains at least one cycle.
A cycle is a path that starts and ends at the same vertex.

Example:
1 → 2 → 3
↑       ↓
└───────┘

Cycle:
1 → 2 → 3 → 1

Properties:
• Contains loops.
• A vertex can be revisited.

------------------------------------------------------------
EDGE-LABELED GRAPH

An edge-labeled graph stores labels on edges.

Example:
(1, 2, A)

Where:
1 = Start Vertex
2 = End Vertex
A = Edge Label

Purpose: Represent names, actions, types, or categories of relationships.

------------------------------------------------------------
WEIGHTED GRAPH

A weighted graph assigns numerical values to edges.

Example:
A --5-- B
 \      |
  2     3
   \    |
     C

Weights may represent:
• Distance
• Cost
• Time
• Priority

------------------------------------------------------------
DIRECTED ACYCLIC GRAPH (DAG)

A DAG is a directed graph that contains no cycles.

Example:
1 → 2 → 4
↓
3

Properties:
• Directed
• No loops
• Useful for scheduling and dependency problems

Examples:
• Course prerequisites
• Project planning
• Build systems

------------------------------------------------------------
SINK VERTEX

A sink is a vertex with incoming edges only.

Example:
1 → 5
2 → 5
3 → 5

Vertex 5 is a sink.

Properties:
• In-Degree > 0
• Out-Degree = 0

------------------------------------------------------------
ADJACENT VERTICES

Two vertices are adjacent if an edge directly connects them.

Example:
A ----- B

A and B are adjacent.

------------------------------------------------------------
DEGREE OF A VERTEX

The degree of a vertex is the number of edges connected to it.

Example:
    B
   / \
  A---C

Degree(A) = 2
Degree(B) = 2
Degree(C) = 2

Note: A self-loop contributes 2 to the degree.

------------------------------------------------------------
DEGREE THEOREM

The sum of all vertex degrees in an undirected graph equals twice the number of edges.

Formula:
Σ Degree(V) = 2E

Reason: Each edge contributes 1 degree to two vertices.

------------------------------------------------------------
IN-DEGREE

The in-degree of a vertex is the number of incoming edges.

Example:
A → B ← C

In-Degree(B) = 2

------------------------------------------------------------
OUT-DEGREE

The out-degree of a vertex is the number of outgoing edges.

Example:
A → B
↓
C

Out-Degree(A) = 2

------------------------------------------------------------
DIRECTED GRAPH THEOREM

In a directed graph, the total in-degree equals the total out-degree.

Formula: Σ(In-Degree) = Σ(Out-Degree) = E
Therefore: Σ(In-Degree) + Σ(Out-Degree) = 2E

Reason: Every edge leaves one vertex and enters another.

------------------------------------------------------------
COMPLETE GRAPH

A complete graph is a graph where every vertex is connected to every other vertex.

Example:
    A
   /|\
  / | \
 B--|--C
  \ | /
   \|/
    D

Notation: Kn

Properties:
• Maximum possible connections.
• Every pair of vertices has an edge.

------------------------------------------------------------
CONNECTIVITY

A graph is connected if there is a path between every pair of vertices.

Connected Graph:
A --- B --- C
      |
      D

Disconnected Graph:
A --- B
C --- D

Properties:
• All vertices are reachable.
• No isolated components.

------------------------------------------------------------
STRONGLY CONNECTED GRAPH

A directed graph is strongly connected if every vertex can reach every other vertex.

Example:
A ↔ B
↑   ↓
D ↔ C

Properties:
• Every vertex is reachable from every other vertex.

------------------------------------------------------------
WEAKLY CONNECTED GRAPH

A directed graph is weakly connected if it becomes connected when edge directions are ignored.

Example:
A → B ← C

Ignoring arrows:
A — B — C

The graph becomes connected.

------------------------------------------------------------
MAXIMUM EDGES IN A GRAPH

The maximum number of edges in an undirected graph occurs when every vertex connects to every other vertex.

Formula: 
Maximum Edges = n(n−1)/2

Example:
n = 4

Maximum Edges = 4(4−1)/2 = 6
This forms a complete graph K₄.

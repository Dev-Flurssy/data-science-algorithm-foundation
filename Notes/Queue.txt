QUEUE

A Queue is a linear data structure in which insertion and deletion are performed at different ends.

Meaning:
• Elements are added at the rear.
• Elements are removed from the front.
• The first element inserted is the first element removed.

Examples:
• Queue at Railway Station
• Queue at Airport
• Queue at Cinema Hall
• Printer Queue
• Customer Service Line

------------------------------------------------------------
DEFINITION OF QUEUE

A Queue is a restricted ordered list in which insertion is done at the REAR and deletion is done at the FRONT.

Meaning:
• Two ends are used.
• REAR is used for insertion.
• FRONT is used for deletion.
• Elements leave in the order they arrive.

------------------------------------------------------------
FIFO PRINCIPLE

Queue follows the FIFO principle.
FIFO = First In First Out
Meaning:
The first element inserted is removed first.

Example:
Enqueue(10)
Enqueue(20)
Enqueue(30)

Queue: FRONT → 10 20 30 ← REAR
Dequeue(): Removed Element = 10

Meaning:
• 10 was inserted first.
• 10 is removed first.

------------------------------------------------------------
QUEUE REPRESENTATION

Suppose:
Q = {10, 15, 20}

Representation:
FRONT → 10 15 20 ← REAR

Meaning:
• 10 is at the front.
• 20 is at the rear.
• Insertion occurs at the rear.
• Deletion occurs at the front.

------------------------------------------------------------
QUEUE TERMINOLOGY

FRONT
Meaning:
• The end from which elements are removed.
• Points to the first element in the queue.

REAR
Meaning:
• The end where new elements are inserted.
• Points to the last element in the queue.

------------------------------------------------------------
QUEUE OPERATIONS

The following operations are used to manage a queue:
isEmpty(): Checks whether the queue has any elements.
isFull():Checks whether the queue is full. Used only in restricted-size queues.
enqueue(el): Adds an element at the rear of the queue.
dequeue(): Removes an element from the front of the queue.
first(): Returns the front element without removing it.

------------------------------------------------------------
ENQUEUE OPERATION

Enqueue means inserting data into the queue.
Meaning:
• A new element is added at the rear.
• Rear position moves forward.

Example:
Empty Queue
FRONT = REAR = -1

Enqueue(10)
Queue: 
FRONT → 10 ← REAR

Enqueue(15)
Queue:
FRONT → 10 15 ← REAR

Meaning:
• 10 entered first.
• 15 entered after 10.
• Both are added at the rear.

------------------------------------------------------------
STEPS OF ENQUEUE

1. Check if the queue is full.

2. If queue is not full:
   • Increment rear by one.
   • Insert the element at rear.
   • Return the queue.

3. Else:
   Queue Overflow

Meaning:
No space is available for a new element.

------------------------------------------------------------
DEQUEUE OPERATION

Dequeue means deleting data from the queue.
Meaning:
• The front element is removed.
• Front position moves forward.

Example:
Queue:
FRONT → 10 15 ← REAR

Dequeue()
Removed Element = 10

Queue:
FRONT → 15 ← REAR

Meaning:
• 10 leaves first because it entered first.

------------------------------------------------------------
STEPS OF DEQUEUE

1. Check if the queue is empty.

2. If queue is not empty:
   • Remove the front element.
   • Increment front by one.
   • Return the queue.

3. Else:
   Queue Underflow

Meaning:
There is no element available for deletion.

------------------------------------------------------------
QUEUE OVERFLOW

Queue Overflow occurs when insertion is attempted in a full queue.
Meaning:
• No empty space is available.
• A new element cannot be inserted.

------------------------------------------------------------
QUEUE UNDERFLOW

Queue Underflow occurs when deletion is attempted in an empty queue.
Meaning:
• No element is available for removal.

Meaning:
Tasks are processed in the same order in which they arrive.

------------------------------------------------------------
QUEUE ADT (ABSTRACT DATA TYPE)

Queue ADT defines what operations can be performed on a queue without describing how the queue is implemented.

Meaning:
• It specifies the behavior of a queue.
• It focuses on operations and rules.
• It does not focus on implementation details.

------------------------------------------------------------
QUEUE ADT OPERATIONS

Create(): Creates an empty queue.
Add(el, Q): Adds the element "el" at the rear of queue Q.
Delete(Q): Removes the front element from queue Q.
getFront(): Returns the front element without removing it.
isEmpty(): Returns True if the queue is empty.
Returns False otherwise.
isFull(): Returns True if the queue is full.
Returns False otherwise.

------------------------------------------------------------
QUEUE ADT AXIOMS

Axioms are rules that define the behavior of queue operations.

------------------------------------------------------------
AXIOM 1

isEmpty(Create()) = True
Meaning: A newly created queue is always empty.

Example:
Q = Create()

Result: isEmpty(Q) = True

------------------------------------------------------------
AXIOM 2

isEmpty(Add(el, Q)) = False
Meaning: After adding an element, the queue is no longer empty.

Example:
Q = Create()
Add(10, Q)

Result: isEmpty(Q) = False

------------------------------------------------------------
AXIOM 3

Delete(Create()) = Error
Meaning: An element cannot be deleted from an empty queue.

Example:
Q = Create()
Delete(Q)

Result: Error

Reason: Queue contains no elements.

------------------------------------------------------------
AXIOM 4

getFront(Create()) = Error
Meaning: The front element cannot be accessed from an empty queue.

Example:
Q = Create()
getFront(Q)

Result: Error

Reason: No element exists in the queue.

------------------------------------------------------------
AXIOM 5

getFront(Add(el, Q))
Meaning:Adding an element at the rear does not change the front element unless the queue was empty.

Case 1:
Queue is Empty

Q = Create()
Add(10, Q)

Result: getFront(Q) = 10

Reason: 10 becomes both front and rear.

------------------------------------------------------------
Case 2:
Queue is Not Empty

Queue:
FRONT → 10 15 ← REAR
Add(20, Q)

Queue:
FRONT → 10 15 20 ← REAR

Result: getFront(Q) = 10
 
Reason:
20 is inserted at the rear.
Front remains unchanged.

------------------------------------------------------------
IMPORTANT POINTS ABOUT QUEUE ADT

• ADT defines operations of a queue.
• ADT does not define implementation.
• Create() creates an empty queue.
• Add() inserts at the rear.
• Delete() removes from the front.
• getFront() returns the front element.
• Queue follows FIFO.
• Deleting from an empty queue causes an error.
• Accessing front of an empty queue causes an error.

------------------------------------------------------------
CREATE OPERATION

Function:
create()

Purpose:
Creates an empty queue.

Initialization:
Q = []
front = 0
rear = -1

Meaning:
• front points to the first element.
• rear = -1 indicates queue is empty.

------------------------------------------------------------
ISEMPTY OPERATION

Function:
isEmpty(front, rear)

Condition:
front > rear
OR
rear == -1

Meaning:
Queue contains no elements.

Returns:
1 → Queue is Empty
0 → Queue is Not Empty

------------------------------------------------------------
ENQUEUE OPERATION

Function:
enqueue(Q, rear)

Purpose:
Inserts an element into the queue.

Steps:
1. Input element.
2. Increment rear.
3. Insert element at rear.
4. Return queue and rear.

Example:
Before:
FRONT = 0
REAR = -1

Queue = []
Insert 10

After:
FRONT = 0
REAR = 0

Queue = [10]

------------------------------------------------------------
Insert 15

After:
FRONT = 0
REAR = 1

Queue = [10, 15]

Meaning:
Every new element joins at the rear.

------------------------------------------------------------
DEQUEUE OPERATION

Function:
dequeue(Q, front, rear)

Purpose:
Removes the front element.

Steps:
1. Check whether queue is empty.
2. Print front element.
3. Increment front.
4. Return updated queue.

Example:
Queue: [10, 15]

FRONT = 0
REAR = 1

Delete Front Element
Removed = 10

After:
FRONT = 1
REAR = 1

Queue: [15]

Meaning:
Front element leaves the queue.

------------------------------------------------------------
DISPLAY OPERATION

Function:
display(Q, front, rear)

Purpose:
Displays queue elements.

Output:
Front Index
Rear Index
Queue Elements

Example:
Queue: [10, 15, 20]

Output:
0 -> 10
1 -> 15
2 -> 20

Meaning:
Elements appear in FIFO order.

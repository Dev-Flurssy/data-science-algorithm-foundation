QUEUE IMPLEMENTATION USING A CLASS

A queue can also be implemented using a class in Python.

Meaning:
• A class combines data and functions into one unit.
• Queue data and operations are grouped together.
• This follows the principles of Object-Oriented Programming (OOP).

------------------------------------------------------------
QUEUE CLASS

Class Name: Queue
Purpose: Represents a queue as an object.

The class contains:
• Queue Data
• Front Pointer
• Rear Pointer
• Queue Operations

------------------------------------------------------------
CONSTRUCTOR / INITIALIZER

Function:
__init__(self, size)
Purpose: Creates an empty queue object.

Initialization:
self.maxSize = size
self.front = 0
self.rear = -1
self.Q = []

Meaning:
• maxSize stores maximum queue size.
• front points to first element.
• rear points to last element.
• Q stores queue elements.
• Queue starts empty.

------------------------------------------------------------
EMPTY QUEUE

Initial State:
Q = []
Front = 0
Rear = -1

Meaning:
No element exists in the queue.

------------------------------------------------------------
ISFULL OPERATION

isFull(): Checks whether the queue is full.

Condition:
self.rear >= self.maxSize - 1

Returns:
1 → Queue is Full
0 → Queue is Not Full

------------------------------------------------------------
EXAMPLE OF ISFULL()

Size = 5
Queue: [10, 20, 30, 40, 50]
Rear = 4

Condition:
4 >= 4

Result:
Queue is Full

------------------------------------------------------------
ISEMPTY OPERATION

isEmpty(): Checks whether the queue is empty.

Condition:
self.front > self.rear
OR
self.rear == -1

Returns:
1 → Queue is Empty
0 → Queue is Not Empty

------------------------------------------------------------
EXAMPLE OF ISEMPTY()

Queue: []
Front = 0
Rear = -1

Result:
Queue is Empty

------------------------------------------------------------
ENQUEUE OPERATION

enqueue(): Inserts an element into the queue.

------------------------------------------------------------
STEPS OF ENQUEUE

1. Check if queue is full.

2. If queue is full:
   Display Overflow message.

3. Otherwise:
   Read element.
   Increment rear.
   Append element to queue.

------------------------------------------------------------
ENQUEUE EXAMPLE

Initial Queue:
[]
Front = 0
Rear = -1

Insert 10

After Insertion:
[10]
Front = 0
Rear = 0

------------------------------------------------------------
Insert 15

After Insertion: [10, 15]
Front = 0
Rear = 1

Queue:
FRONT → 10 15 ← REAR

Meaning:
New elements are always added at the rear.

------------------------------------------------------------
QUEUE OVERFLOW

Overflow occurs when insertion is attempted in a full queue.

Example:
Size = 3

Queue: [10, 20, 30]
Insert 40

Result:
Overflow:
No more place for the Queue

Meaning:
Queue has reached maximum capacity.

------------------------------------------------------------
DEQUEUE OPERATION

dequeue(): an element from the front.

------------------------------------------------------------
STEPS OF DEQUEUE

1. Check if queue is empty.

2. If queue is empty:
   Display Underflow message.

3. Otherwise:
   Display front element.
   Increment front.

------------------------------------------------------------
DEQUEUE EXAMPLE

Queue: [10, 15, 20]
Front = 0
Rear = 2

Delete Element
Deleted = 10

After Deletion:
Front = 1
Rear = 2

Queue:
FRONT → 15 20 ← REAR

Meaning:
The first inserted element is removed first.

------------------------------------------------------------
QUEUE UNDERFLOW

Underflow occurs when deletion is attempted from an empty queue.

Example:
Queue = []
Front = 0
Rear = -1

Delete()

Result:
Underflow:
There is no element in the Queue

Meaning:
No element exists for deletion.

------------------------------------------------------------
DISPLAY OPERATION

display(): Displays all elements of the queue.

------------------------------------------------------------
DISPLAY WHEN QUEUE IS EMPTY

Condition:
isEmpty() == 1

Output: 
Queue is Empty

Meaning:
No data exists in the queue.

------------------------------------------------------------
DISPLAY WHEN QUEUE IS FULL

Example:
Queue: [10, 20, 30, 40, 50]

Output:
0 -> 10
1 -> 20
2 -> 30
3 -> 40
4 -> 50

Queue is Full

Meaning:
Maximum capacity has been reached.

------------------------------------------------------------
DISPLAY WHEN QUEUE IS NOT FULL

Example:
Queue: [10, 20, 30]

Output:
0 -> 10
1 -> 20
2 -> 30

Meaning:
Displays all queue elements from front to rear.

------------------------------------------------------------
OBJECT CREATION

Statement:
Qu = Queue(size)

Meaning:
• Qu is an object of Queue class.
• Queue methods can be called using Qu.

Examples:
Qu.enqueue()
Qu.dequeue()
Qu.display()

------------------------------------------------------------
ADVANTAGES OF CLASS IMPLEMENTATION

• Better organization of code.
• Supports Object-Oriented Programming.
• Easy maintenance.
• Easy code reuse.
• Data and methods are grouped together.

------------------------------------------------------------
CLASS QUEUE VS LIST QUEUE

LIST IMPLEMENTATION

• Uses independent functions.
• Queue variables passed as parameters.

------------------------------------------------------------
CLASS IMPLEMENTATION

• Uses methods inside a class.
• Data belongs to the object.
• Easier to manage large programs.

------------------------------------------------------------
QUEUE IMPLEMENTATION USING QUEUE MODULE

Python provides a built-in Queue class through the queue module.

Meaning:
• Queue operations are already implemented.
• No need to manually manage front and rear.
• Queue follows FIFO automatically.
• It is part of Python Standard Library.

------------------------------------------------------------
QUEUE MODULE

Import Statement:
from queue import Queue

Purpose:
Imports the Queue class from the queue module.

------------------------------------------------------------
CREATING A QUEUE

Statement:
Q = Queue(size)

Example:
Q = Queue(5)

Meaning:
• Queue capacity is 5.
• Maximum 5 elements can be inserted.
• Built-in queue object is created.

------------------------------------------------------------
QUEUE SIZE

Queue(size): The size parameter specifies the maximum number of elements.

Example:
Q = Queue(4)

Maximum Elements:
4

------------------------------------------------------------
UNLIMITED QUEUE

Queue(0) or Queue(size <= 0)

Meaning:
Queue size becomes unlimited.
No fixed maximum capacity exists.

------------------------------------------------------------
BUILT-IN QUEUE METHODS

full(): Checks whether the queue is full.

Returns:
True → Queue is Full
False → Queue is Not Full

------------------------------------------------------------

empty(): Checks whether the queue is empty.

Returns:
True → Queue is Empty
False → Queue is Not Empty

------------------------------------------------------------

put(data): Inserts an element into the queue.

Example:
Q.put(10)

Meaning:
10 is added to the rear.

------------------------------------------------------------

get(): Removes an element from the queue.

Example:
Q.get()

Meaning:
Front element is deleted and returned.

------------------------------------------------------------

q.queue: Returns all queue elements.

Used for displaying queue contents.

------------------------------------------------------------
ENQUEUE OPERATION

enqueue(Q): Inserts an element into the queue.

------------------------------------------------------------
STEPS OF ENQUEUE

1. Check whether queue is full.

2. If queue is full:
   Display error message.

3. Otherwise:
   Read data.
   Insert using put().

------------------------------------------------------------
ENQUEUE EXAMPLE

Queue: []

Insert 10
Q.put(10)

Queue: [10]

------------------------------------------------------------

Insert 20
Q.put(20)

Queue: [10, 20]

------------------------------------------------------------

Insert 30
Q.put(30)

Queue: [10, 20, 30]

Meaning:
Elements are inserted at the rear.

------------------------------------------------------------
QUEUE OVERFLOW

Condition:
Q.full() == True

Example:
Size = 3

Queue: [10, 20, 30]

Insert 40

Result:
There is NO SPACE in the Queue

Meaning:
Queue has reached maximum capacity.

------------------------------------------------------------
DEQUEUE OPERATION

dequeue(Q): Deletes an element from the queue.

------------------------------------------------------------
STEPS OF DEQUEUE

1. Check whether queue is empty.

2. If queue is empty:
   Display error message.

3. Otherwise:
   Delete element using get().

------------------------------------------------------------
DEQUEUE EXAMPLE

Queue: [10, 20, 30]

Delete Element
Q.get()
Deleted Element: 10

Queue: [20, 30]

Meaning:
First inserted element leaves first.

------------------------------------------------------------
QUEUE UNDERFLOW

Condition:
Q.empty() == True

Example:

Queue:
[]
Delete Element

Result:
There is NO DATA in the Queue

Meaning:
Queue contains no elements.

------------------------------------------------------------
DISPLAY OPERATION

Display(Q): Displays all queue elements.

Queue elements are obtained using:
Q.queue

------------------------------------------------------------
DISPLAY EXAMPLE

Queue: [10, 20, 30]

Output: 10 20 30

Meaning:
Elements are displayed in FIFO order.

------------------------------------------------------------
DISPLAY WHEN QUEUE IS EMPTY

Condition:
Q.empty() == True

Output:
Queue is EMPTY

Meaning:
No elements exist in the queue.

------------------------------------------------------------
DISPLAY WHEN QUEUE IS FULL

Condition:
Q.full() == True

Output:
10 20 30 40

Queue is Full

Meaning:
Maximum queue capacity has been reached.

------------------------------------------------------------
IMPORTANT ADVANTAGE OF QUEUE MODULE

In previous implementations:

• Front and Rear were managed manually.
• Memory spaces created by deletions could not be reused easily.

Queue Module:

• Automatically manages queue operations.
• No manual handling of front and rear.
• Easier and safer implementation.

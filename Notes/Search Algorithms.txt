7. SEARCH ALGORITHMS

A search algorithm is a method used to locate a specific item within a collection of data.

------------------------------------------------------------
WHY SEARCH ALGORITHMS ARE NEEDED

Searching is one of the most common operations in computer science.

Examples:
• Finding a contact in a phone book
• Searching a student record
• Looking up a product ID
• Retrieving customer information

Problem:
Large datasets make manual searching inefficient.

Solution:
Search algorithms help locate data quickly and efficiently.

------------------------------------------------------------
SEARCH INPUTS

Most search algorithms require:

• Array or Collection (A)
• Number of Elements (n)
• Search Key (x)

Output:

• Position of x if found
• "Not Found" if x does not exist

------------------------------------------------------------
TYPES OF SEARCH ALGORITHMS

1. Unordered Linear Search
2. Ordered Linear Search
3. Chunk Search
4. Binary Search

------------------------------------------------------------
7.1 UNORDERED LINEAR SEARCH

Unordered Linear Search is used when data is not sorted.

Definition:
Search each element one by one from the beginning until the item is found.

------------------------------------------------------------
EXAMPLE

Array:

[35, 17, 26, 34, 8, 23, 49, 9]

Search:

34

------------------------------------------------------------
STEP 1

Compare 34 with 35

Not Found

------------------------------------------------------------
STEP 2

Compare 34 with 17

Not Found

------------------------------------------------------------
STEP 3

Compare 34 with 26

Not Found

------------------------------------------------------------
STEP 4

Compare 34 with 34

Found

------------------------------------------------------------
RESULT

Position = 4

Comparisons = 4

------------------------------------------------------------
ELEMENT NOT FOUND

Search:

19

Array:

[35, 17, 26, 34, 8, 23, 49, 9]

Process:

Compare every element

35
17
26
34
8
23
49
9

Result:

19 Not Found

Comparisons = 8

------------------------------------------------------------
TIME COMPLEXITY

Worst Case:

O(n)

Formula:

T(n) = n

------------------------------------------------------------
CHARACTERISTICS

Advantages:
• Very simple
• Works on any data

Disadvantages:
• Slow for large datasets

------------------------------------------------------------
7.2 ORDERED LINEAR SEARCH

Ordered Linear Search is used when data is already sorted.

Definition:
Search from left to right but stop early when the current value becomes larger than the target.

------------------------------------------------------------
EXAMPLE

Sorted Array:

[8, 9, 17, 23, 26, 34, 35, 49]

Search:

34

------------------------------------------------------------
STEP 1

34 > 8

Continue

------------------------------------------------------------
STEP 2

34 > 9

Continue

------------------------------------------------------------
STEP 3

34 > 17

Continue

------------------------------------------------------------
STEP 4

34 > 23

Continue

------------------------------------------------------------
STEP 5

34 > 26

Continue

------------------------------------------------------------
STEP 6

34 = 34

Found

------------------------------------------------------------
RESULT

Position = 6

------------------------------------------------------------
EARLY STOPPING EXAMPLE

Search:

19

Array:

[8, 9, 17, 23, 26, 34, 35, 49]

------------------------------------------------------------
STEP 1

19 > 8

Continue

------------------------------------------------------------
STEP 2

19 > 9

Continue

------------------------------------------------------------
STEP 3

19 > 17

Continue

------------------------------------------------------------
STEP 4

19 < 23

Stop Search

------------------------------------------------------------
RESULT

19 Not Found

Reason:
All remaining elements are larger than 19.

------------------------------------------------------------
TIME COMPLEXITY

Worst Case:

O(n)

Formula:

T(n) = 2n

------------------------------------------------------------
ADVANTAGE OVER UNORDERED SEARCH

Can stop earlier when the target cannot exist.

------------------------------------------------------------
7.3 CHUNK SEARCH

Chunk Search divides an ordered list into smaller groups called chunks.

Definition:
Search chunk boundaries first, then perform linear search inside the selected chunk.

------------------------------------------------------------
WHY CHUNK SEARCH IS USED

Problem:

Linear Search examines too many elements.

Solution:

Divide data into manageable chunks.

------------------------------------------------------------
EXAMPLE

Array:

[8, 9, 17, 23, 26, 34, 35, 49]

Chunk Size = 2

------------------------------------------------------------
CHUNKS

Chunk 1:

[8, 9]

------------------------------------------------------------

Chunk 2:

[17, 23]

------------------------------------------------------------

Chunk 3:

[26, 34]

------------------------------------------------------------

Chunk 4:

[35, 49]

------------------------------------------------------------
SEARCH FOR 34

Check Last Elements:

9

23

34

Found correct chunk

------------------------------------------------------------
PERFORM LINEAR SEARCH

Chunk:

[26, 34]

Search:

26

34

Found

------------------------------------------------------------
RESULT

Position = 6

------------------------------------------------------------
TIME COMPLEXITY

Formula:

T(n) = n/c + 2c

Where:

n = Number of Elements

c = Chunk Size

------------------------------------------------------------
ADVANTAGES

• Faster than ordinary linear search
• Fewer comparisons

------------------------------------------------------------
DISADVANTAGES

• More complex implementation
• Still slower than binary search

------------------------------------------------------------
7.4 BINARY SEARCH

Binary Search is an efficient algorithm that repeatedly divides the search space into two halves.

Definition:
Search by repeatedly eliminating half the remaining data.

Requirement:
Data must be sorted.

------------------------------------------------------------
WHY BINARY SEARCH IS FAST

Each comparison removes half of the remaining elements.

------------------------------------------------------------
EXAMPLE

Array:

[8, 9, 17, 23, 26, 34, 35, 49]

Search:

26

------------------------------------------------------------
STEP 1

Middle Element:

23

26 > 23

Search Right Half

------------------------------------------------------------
Remaining:

[26, 34, 35, 49]

------------------------------------------------------------
STEP 2

Middle Element:

34

26 < 34

Search Left Half

------------------------------------------------------------
Remaining:

[26]

------------------------------------------------------------
STEP 3

26 = 26

Found

------------------------------------------------------------
RESULT

Position = 5

------------------------------------------------------------
ELEMENT NOT FOUND

Search:

30

Array:

[8, 9, 17, 23, 26, 34, 35, 49]

------------------------------------------------------------
STEP 1

Middle:

23

Search Right

------------------------------------------------------------
STEP 2

Middle:

34

Search Left

------------------------------------------------------------
STEP 3

26

Search Right

------------------------------------------------------------
NO ELEMENTS REMAIN

Result:

30 Not Found

------------------------------------------------------------
TIME COMPLEXITY

Worst Case:

O(log n)

Formula:

T(n) = 2log₂(n)

------------------------------------------------------------
WHY BINARY SEARCH IS BETTER

Array Size = 1,000

Linear Search:

Up to 1,000 comparisons

------------------------------------------------------------

Binary Search:

About 10 comparisons

------------------------------------------------------------
ARRAY SIZE = 1,000,000

Linear Search:

Up to 1,000,000 comparisons

------------------------------------------------------------

Binary Search:

About 20 comparisons

------------------------------------------------------------
COMPARISON OF SEARCH ALGORITHMS

Algorithm               Time Complexity

Unordered Linear Search     O(n)

Ordered Linear Search       O(n)

Chunk Search                O(n/c + 2c)

Binary Search               O(log n)

------------------------------------------------------------
WHEN TO USE EACH SEARCH

Unordered Linear Search

Use When:
• Data is unsorted

------------------------------------------------------------

Ordered Linear Search

Use When:
• Data is sorted
• Dataset is small

------------------------------------------------------------

Chunk Search

Use When:
• Ordered data
• Medium-sized datasets

------------------------------------------------------------

Binary Search

Use When:
• Data is sorted
• Fast searching is required

------------------------------------------------------------
ADVANTAGES OF BINARY SEARCH

• Extremely fast
• Reduces search space quickly
• Efficient for large datasets

------------------------------------------------------------
DISADVANTAGES OF BINARY SEARCH

• Requires sorted data
• More complex than linear search

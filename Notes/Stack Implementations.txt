IMPLEMENTATION OF STACK USING DICTIONARY

A Stack can be implemented using a Dictionary.

Meaning:
A dictionary stores data as Key-Value pairs.
The Key acts as the index (Top position).
The Value acts as the stack element.
The stack size is restricted.

Example:
S = {
      0 : 10,
      1 : 20,
      2 : 30
    }

TOP = 2

Meaning:
0, 1, and 2 are keys.
10, 20, and 30 are values.
30 is the top element.

------------------------------------------------------------
CREATE OPERATION

A dictionary is created as an empty stack.

Python:
S = {}
top = -1

Meaning:
An empty dictionary is created.
Top = -1 means the stack is empty.

Example:
Stack = {}
Top = -1

------------------------------------------------------------
ISFULL OPERATION

The isFull() function checks whether the stack is full.

Condition:
top >= size - 1

Meaning:
When Top reaches the maximum size, the stack is full.

Returns:
1 → Stack Full
0 → Stack Not Full

Example:
Size = 3
Top = 2
2 >= 3-1

Stack is Full

------------------------------------------------------------
ISEMPTY OPERATION

The isEmpty() function checks whether the stack is empty.

Condition:
top <= -1

Meaning:
When Top becomes -1, there are no elements in the stack.

Returns:
1 → Stack Empty
0 → Stack Not Empty

Example:
Top = -1
Stack is Empty

------------------------------------------------------------
PUSH OPERATION USING DICTIONARY

Push inserts an element at the top of the stack.

Steps:
1. Check if stack is full.
2. Increment Top by 1.
3. Insert element into dictionary.

Statement:
top += 1
S[top] = data

Example:
Before Push(40)
S = {
      0 : 10,
      1 : 20,
      2 : 30
    }
TOP = 2

After Push(40)
S = {
      0 : 10,
      1 : 20,
      2 : 30,
      3 : 40
    }
TOP = 3

Meaning:
40 becomes the new top element.

------------------------------------------------------------
POP OPERATION USING DICTIONARY

Pop removes the topmost element.

Steps:
1. Check if stack is empty.
2. Access S[top].
3. Delete S[top].
4. Decrement Top.

Statement:
del S[top]
top -= 1

Example:
Before Pop()
S = {
      0 : 10,
      1 : 20,
      2 : 30
    }
TOP = 2

After Pop()
S = {
      0 : 10,
      1 : 20
    }
TOP = 1

Removed Element = 30
Meaning:
The top element is deleted.

------------------------------------------------------------
PEEK OPERATION USING DICTIONARY

Peek displays the element at the top.

Statement:
S[top]

Example:
S = {
      0 : 10,
      1 : 20,
      2 : 30
    }
TOP = 2

Peek()
Output: 30

Meaning:
The top element is displayed.
The stack remains unchanged.

------------------------------------------------------------
DISPLAY OPERATION USING DICTIONARY

Display shows all elements in reverse order.

Example:
S = {
      0 : 10,
      1 : 20,
      2 : 30
    }
TOP = 2

Output:
2 → 30
1 → 20
0 → 10

Meaning:
Elements are displayed from top to bottom.

STACK USING CLASS

A Stack can also be implemented using a Class.

Meaning:
Data and operations are grouped together.
Stack operations become easier to manage.
Object-Oriented Programming concepts are used.

------------------------------------------------------------
CLASS ATTRIBUTES

The Stack class contains:
S
Top
MaxSize

Meaning:
S → Stores stack elements
Top → Stores position of top element
MaxSize → Stores maximum stack capacity

Example:
self.S = []
self.top = -1
self.maxSize = size

------------------------------------------------------------
CLASS METHOD: ISFULL

Checks whether the stack is full.

Condition:
self.top >= self.maxSize - 1

Meaning:
If Top reaches the last position,
the stack becomes full.

Returns:
1 → Full
0 → Not Full

------------------------------------------------------------
CLASS METHOD: ISEMPTY

Checks whether the stack is empty.

Condition:
self.top <= -1

Meaning:
No element exists in the stack.

Returns:
1 → Empty
0 → Not Empty

------------------------------------------------------------
CLASS METHOD: PUSH

Adds an element to the stack.

Steps:
1. Check isFull().
2. Increment Top.
3. Insert the element into the list.

Meaning:
6 becomes the new top element.

IMPLEMENTATION OF STACK USING QUEUE MODULE

Python provides a built-in stack using:
queue.LifoQueue()
LIFO = Last In First Out

Meaning:
The Queue module provides stack functionality.
The stack size can be restricted.

Example:
import queue
Stack = queue.LifoQueue(3)

Meaning:
Creates a stack of size 3.

------------------------------------------------------------
PUSH USING LIFOQUEUE

Method:
put()

Example:
Stack.put(10)
Stack.put(20)
Stack.put(30)

Stack:
TOP
30
20
10

Meaning:
Elements are inserted at the top.

------------------------------------------------------------
POP USING LIFOQUEUE

Method:
get()

Example:

10

Stack.get()

Output:
30

Stack:

Meaning:
The last inserted element is removed.

------------------------------------------------------------
DELIMITER MATCHING

Delimiter Matching checks whether opening and closing symbols match correctly.

Delimiters:
()
[]
{}

Meaning:
Every opening delimiter must have a matching closing delimiter.

------------------------------------------------------------
CORRECTLY MATCHED EXPRESSIONS

Examples:
a = b + (c - d) + (e - f)
p[10] = h[(a + b)] + (j + k)

Meaning:
Every opening bracket has a matching closing bracket.

------------------------------------------------------------
INCORRECTLY MATCHED EXPRESSIONS

Examples:
a = (b + c) - (d + e))
p[10] = h[(a + b] - (c + d)

Meaning:
Opening and closing brackets do not match correctly.

------------------------------------------------------------
DELIMITER MATCHING ALGORITHM

Steps:
1. Read expression character by character.
2. If opening delimiter:
       Push onto stack.
3. If closing delimiter:
       Compare with top of stack.
4. If matching:
       Pop from stack.
5. If not matching:
       Report error.
6. If stack becomes empty at the end:
       Expression is valid.

Meaning:
Opening brackets enter the stack.
Matching closing brackets remove them.
The stack must be empty at the end.

------------------------------------------------------------
EXAMPLE OF DELIMITER MATCHING

Expression:
a[5] + (b - {c*(d-e)+(f-g)})

Processing:
Push [
Pop ]

Push (
Push {
Push (
Pop )

Push (
Pop )
Pop }
Pop )

Stack Empty

Result:
Expression is Well Parenthesized

Meaning:
All delimiters are matched correctly.

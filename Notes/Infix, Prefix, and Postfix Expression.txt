IMPLEMENTATION OF STACK USING DICTIONARY

A Stack can be implemented using a Dictionary.

Meaning:
INFIX, PREFIX AND POSTFIX EXPRESSIONS

An arithmetic expression can be written in three different forms:
Infix Expression
Prefix Expression
Postfix Expression

Meaning:
The difference lies in the position of the operator.

------------------------------------------------------------
INFIX EXPRESSION

In an Infix Expression, the operator is placed between operands.

Example:
A + B

Meaning:
The operator '+' is written between A and B.
This is the normal form humans use.

Examples:
A + B
A * B
A + B * C
(A + B) * C

------------------------------------------------------------
PREFIX EXPRESSION

In a Prefix Expression, the operator comes before the operands.

Example:
+AB

Meaning:
The '+' operator is written before A and B.

Examples:
+AB
*AB
+A*BC

------------------------------------------------------------
POSTFIX EXPRESSION

In a Postfix Expression, the operator comes after the operands.

Example:
AB+

Meaning:
The '+' operator is written after A and B.

Examples:
AB+
AB*
ABC*+

------------------------------------------------------------
COMPARISON OF ALL THREE FORMS

Expression: A + B
Infix: A + B
Prefix: +AB
Postfix: AB+

------------------------------------------------------------
WHY COMPUTERS PREFER POSTFIX

Postfix expressions do not require operator precedence rules.

Meaning:
No brackets are needed.
No ambiguity exists.
Evaluation becomes easier.
The stack can evaluate expressions directly.

Example:
Infix: A + B * C
Postfix: ABC*+

Meaning:
Multiplication is automatically evaluated first.
No precedence checking is needed during evaluation.

------------------------------------------------------------
OPERATOR PRECEDENCE

Precedence determines which operator is evaluated first.
OPERATOR PRECEDENCE TABLE

| Priority | Operators                    | Meaning                    |
|-----------|-----------------------------|----------------------------|
| 4         | **, Unary -, not            | Highest Precedence         |
| 3         | *, /, div, mod, and         | High Precedence            |
| 2         | +, -, or                    | Medium Precedence          |
| 1         | <, <=, <>, >=, >           | Lowest Precedence          |


Meaning:
Higher priority operators are evaluated first.

Example:
A + B * C

Output: A + (B * C)
Because: * has higher precedence than +

------------------------------------------------------------
ASSOCIATIVITY OF OPERATORS

When two operators have the same precedence:
Exponentiation (**)
Evaluate Right to Left

Example:
2 ** 3 ** 2
Meaning: 2 ** (3 ** 2)

Other Operators
Evaluate Left to Right

Example:
10 - 5 - 2
Meaning: (10 - 5) - 2

------------------------------------------------------------
INFIX TO POSTFIX CONVERSION

Computers convert infix expressions into postfix expressions.
Postfix expressions are easier to evaluate using stacks.

Tools Used:
Stack

------------------------------------------------------------
RULES FOR INFIX TO POSTFIX CONVERSION

Rule 1:
If operand appears Output it immediately.

Rule 2:
If '(' appears Push it onto stack.

Rule 3: 
If operator appears Push if stack is empty.
Otherwise compare precedence.

Rule 4:
If ')' appears Pop until '(' is found.

Rule 5:
After expression ends 
Pop all remaining operators.

------------------------------------------------------------
EXAMPLE 1

Convert:
A + B * C

Step 1: Read A
Output: A

Stack: Empty

------------------------------------------------------------
Read +

Output: A
Stack: +

------------------------------------------------------------
Read B

Output: AB
Stack: +

------------------------------------------------------------
Read *

Output: AB
Stack: + *

Meaning:
* has higher precedence than +
Push *

------------------------------------------------------------
Read C

Output: ABC

Stack: + *

------------------------------------------------------------
Expression Ends

Pop *
Output: ABC*

Pop +
Output: ABC*+

------------------------------------------------------------
Final Postfix Expression:

ABC*+

------------------------------------------------------------
EXAMPLE 2

Convert: A/(B+C)*D

------------------------------------------------------------
Read A

Output: A
Stack: Empty

------------------------------------------------------------
Read /

Output: A
Stack: /

------------------------------------------------------------
Read (

Output: A
Stack: / (

------------------------------------------------------------
Read B

Output: AB
Stack: / (

------------------------------------------------------------
Read +

Output: AB
Stack: / ( +

------------------------------------------------------------
Read C

Output: ABC

Stack: / ( +

------------------------------------------------------------
Read )

Pop until (
Output: ABC+
Stack: /

------------------------------------------------------------
Read *

Output: ABC+
Stack: / *

------------------------------------------------------------
Read D

Output: ABC+D
Stack: / *

------------------------------------------------------------
Expression Ends

Pop *
Output: ABC+D*
Pop /

Output: ABC+D*/

------------------------------------------------------------
Final Postfix Expression:

ABC+D*/

------------------------------------------------------------
ALGORITHM FOR INFIX TO POSTFIX

1. Initialize an empty stack.
2. Read expression from left to right.
3. If operand:
     Output it.
4. If operator:
     Push according to precedence.
5. If '(':
     Push onto stack.
6. If ')':
     Pop until '(' appears.
7. Repeat until expression ends.
8. Pop remaining operators.
9. End.

------------------------------------------------------------
POSTFIX EXPRESSION EVALUATION

After conversion, the postfix expression is evaluated using a stack.

Meaning:
Operands are pushed.
Operators perform calculations on operands.

------------------------------------------------------------
ALGORITHM FOR POSTFIX EVALUATION

1. Initialize a stack.
2. Read next symbol.
3. If operand:
      Push onto stack.
4. If operator:
      Pop required operands.
      Perform operation.
      Push result.
5. Repeat until expression ends.
6. Pop final result.
7. End.

------------------------------------------------------------
EXAMPLE OF POSTFIX EVALUATION

Evaluate: 1 3 5 * +

------------------------------------------------------------
Read 1

Stack: 1

------------------------------------------------------------
Read 3

Stack:
1
3

------------------------------------------------------------
Read 5

Stack:
1
3
5

------------------------------------------------------------
Read *

Operation:
3 × 5 = 15

Stack:
1
15

------------------------------------------------------------
Read +

Operation:
1 + 15 = 16

Stack:
16

------------------------------------------------------------
Final Result:
16

CALCULATE FUNCTION

The calculate() function performs arithmetic operations.

Operations Supported:
*
/
+
-
%

Meaning:
Depending on the operator received,
the corresponding operation is performed.

Example:
calculate(5,3,'+')
Output: 8

APPLICATION OF STACK IN EXPRESSION EVALUATION

Uses:
Infix to Postfix Conversion

Compiler Design
Expression Processing

------------------------------------------------------------
RECURSION

Recursion occurs when a function calls itself.
The same function repeatedly invokes itself.
The calls continue until a stopping condition is reached.

Example:
def factorial(n):
    if n == 1:
        return 1
    return n * factorial(n-1)

Meaning:
factorial() calls itself repeatedly.

------------------------------------------------------------
ACTIVATION RECORD

Each function call creates an Activation Record.
The system stores information about the function call.

Contents:
Function Parameters
Local Variables
Return Address
Stack Pointer (SP)
Returned Value

------------------------------------------------------------
RUN-TIME STACK

Activation Records are stored in a Run-Time Stack.
Every function call creates a new record.
Records are removed when functions finish execution.

Example:
main()
   ↓
f1()
   ↓
f2()
   ↓
f3()

Run-Time Stack:
Top
f3()
f2()
f1()
main()

Bottom
Meaning:
The most recent function call stays on top.

------------------------------------------------------------
STACK POINTER (SP)

SP = Stack Pointer

Meaning:
Points to the current activation record.
Moves upward when functions are called.
Moves downward when functions return.

------------------------------------------------------------
RECURSIVE STRING REVERSAL

Input:
A
b
c
z

Program:
rev()
Output:
z
c
b
A

Meaning:
Characters are stored through recursive calls.
During return, they are printed in reverse order.

------------------------------------------------------------
NON-RECURSIVE STRING REVERSAL USING STACK

Steps:
1. Push all characters onto stack.
2. Pop characters one by one.
3. Display popped characters.

Example:
Input:
ABCD

Stack:
A
B
C
D

Pop Sequence:
D
C
B
A

Output:
DCBA

Meaning:
The stack automatically reverses the order.

------------------------------------------------------------
ADVANTAGES OF RECURSION

Reduces code complexity
Easy to solve repetitive problems
Uses stack automatically

Meaning:
Some algorithms become simpler with recursion.

------------------------------------------------------------
DISADVANTAGES OF RECURSION

Uses extra memory
Can lead to stack overflow
May be slower than iteration

Meaning:
Each function call requires an activation record.

DETERMINISTIC AND RANDOMIZED ALGORITHMS

Algorithms can be classified based on how they produce their results.

------------------------------------------------------------
DETERMINISTIC ALGORITHM

A deterministic algorithm always produces the same output for a given input.
Given the same input, the algorithm follows the same steps and generates the same result every time.

Example:
Input: 5, 3, 2
Output: 2, 3, 5

If executed again:
Input: 5, 3, 2
Output: 2, 3, 5

Result: The output never changes.

------------------------------------------------------------
PROPERTIES OF DETERMINISTIC ALGORITHMS

• Predictable behavior
• Same execution path every time
• Same output for the same input
• Easier to debug and test

Examples:
• Binary Search
• Merge Sort
• Insertion Sort
• Linear Search

------------------------------------------------------------
RANDOMIZED ALGORITHM

A randomized algorithm uses random choices during execution.
The algorithm may follow different execution paths even when the input remains the same.

Example:
Input: 5, 3, 2

Run 1: Chooses Path A
Run 2: Chooses Path B
Run 3: Chooses Path C

Result: Execution differs each time.

------------------------------------------------------------
PROPERTIES OF RANDOMIZED ALGORITHMS

• Uses random decisions
• Different execution paths
• Often faster in practice
• Reduces worst-case situations

Advantages:
• Simpler design
• Better average performance
• Handles difficult inputs effectively

------------------------------------------------------------
DETERMINISTIC VS RANDOMIZED ALGORITHMS

Deterministic Algorithm
Input → Fixed Steps → Same Output

Randomized Algorithm
Input → Random Choice → Different Execution Paths → Output

------------------------------------------------------------
COMPARISON

Deterministic Algorithms:
• Predictable
• Same output every time
• Same execution steps

Randomized Algorithms:
• Unpredictable execution path
• Uses randomness
• May produce different outcomes

------------------------------------------------------------
TYPES OF RANDOMIZED ALGORITHMS

There are two major types:
• Monte Carlo Algorithms
• Las Vegas Algorithms

------------------------------------------------------------
MONTE CARLO ALGORITHMS

A Monte Carlo algorithm may produce an incorrect answer, but the probability of error is very small.

Properties:
• Faster execution
• Small chance of error
• High probability of correct results

Example:
Input: Prime Number Test
Result: The algorithm may occasionally be wrong.

------------------------------------------------------------
MONTE CARLO CHARACTERISTICS

Advantages:
• Extremely fast
• Efficient for large problems

Disadvantages:
• Result may not always be correct

------------------------------------------------------------
LAS VEGAS ALGORITHMS

A Las Vegas algorithm always produces the correct result.

Properties:
• Output is always correct
• Running time may vary
• Uses randomization internally

Example:
Randomized Quick Sort

Result: Correctly sorted array every time.

------------------------------------------------------------
LAS VEGAS CHARACTERISTICS

Advantages:
• Guaranteed correct answer
• Benefits from randomization

Disadvantages:
• Runtime may be unpredictable

------------------------------------------------------------
MONTE CARLO VS LAS VEGAS

Monte Carlo
Output: May be incorrect
Runtime: Usually predictable

Goal: Fast approximation

Las Vegas
Output: Always correct
Runtime: May vary

Goal: Correct solution

------------------------------------------------------------
WHY USE RANDOMIZED ALGORITHMS?

Problem: Certain inputs create poor performance for deterministic algorithms.
Solution: Introduce randomness.

Benefits:
• Avoid worst-case inputs
• Improve average performance
• Simplify implementation

------------------------------------------------------------
REAL-WORLD APPLICATIONS

Randomized Algorithms are used in:
• Artificial Intelligence
• Cryptography
• Network Routing
• Machine Learning
• Data Analysis

ONLINE VS OFFLINE ALGORITHMS

Algorithms can also be classified based on when input becomes available.

------------------------------------------------------------
ONLINE ALGORITHM

An online algorithm receives input gradually during execution.
The algorithm must make decisions without knowing future inputs.

Characteristics:
• Future data is unknown
• Decisions are made immediately
• Cannot revise previous decisions easily

------------------------------------------------------------
ONLINE ALGORITHM EXAMPLE

Food Delivery System

Orders Arrive:
Time 1: Order A
Time 2: Order B
Time 3: Order C

The system must decide immediately how to assign deliveries.
Problem: Future orders are unknown.

------------------------------------------------------------
PROPERTIES OF ONLINE ALGORITHMS

• Handles real-time data
• Works with incomplete information
• Used in dynamic environments

Applications:
• GPS Navigation
• Stock Trading
• Operating Systems
• Network Routing

------------------------------------------------------------
OFFLINE ALGORITHM

An offline algorithm knows all inputs before execution begins.
The complete data set is available before processing starts.

Characteristics:
• Full knowledge of inputs
• Can plan better solutions
• Often achieves optimal results

------------------------------------------------------------
OFFLINE ALGORITHM EXAMPLE

Exam Scores

Since all data is available before processing begins, sorting can be optimized.

------------------------------------------------------------
ONLINE VS OFFLINE ALGORITHMS

• Network Routing

EXACT, APPROXIMATE, HEURISTIC, AND OPERATIONAL ALGORITHMS

Algorithms can be classified based on how they approach problem solving and optimization.

------------------------------------------------------------
EXACT ALGORITHMS

An exact algorithm always finds the optimal (best possible) solution to a problem.
The algorithm guarantees the correct and optimal answer.

Properties:
• Always produces the best solution
• High accuracy
• May require large amounts of time and memory
• Often impractical for very large inputs

------------------------------------------------------------
EXACT ALGORITHM EXAMPLE

Problem: Find the shortest path between cities.
Result: The algorithm guarantees the shortest possible path.

Advantages:
• Perfect solution
• Guaranteed correctness

Disadvantages:
• Slow for large problems
• High computational cost

------------------------------------------------------------
APPROXIMATION ALGORITHMS

An approximation algorithm produces a solution that is close to the optimal solution.
The algorithm guarantees that its answer is within a specific factor of the optimal answer.

Properties:
• Faster than exact algorithms
• Provides near-optimal results
• Comes with a performance guarantee

------------------------------------------------------------
APPROXIMATION FACTOR

A c-approximation algorithm guarantees:

Approximate Solution ≤ c × Optimal Solution
Meaning: The solution will never be worse than the specified factor c compared to the optimal solution.

------------------------------------------------------------
APPROXIMATION ALGORITHM EXAMPLE

Traveling Salesman Problem (TSP)

Problem: Finding the absolute shortest route is extremely expensive.
Solution: Use an approximation algorithm to find a route close to the shortest one.

Advantages:
• Faster execution
• Predictable solution quality

Disadvantages:
• Does not always produce the perfect answer

------------------------------------------------------------
HEURISTIC ALGORITHMS

A heuristic algorithm aims to find a good solution quickly without guaranteeing the optimal solution.
The algorithm uses practical rules or educated guesses to solve a problem.

Properties:
• Fast execution
• Simple implementation
• No guarantee of optimality

------------------------------------------------------------
HEURISTIC ALGORITHM EXAMPLE

GPS Navigation
Instead of examining every possible route, the system may choose roads that appear most promising.

Result:
Usually near-optimal
Not guaranteed optimal

Advantages:
• Very fast
• Efficient for large problems

Disadvantages:
• May miss the best solution

------------------------------------------------------------
EXACT VS APPROXIMATION VS HEURISTIC

Exact Algorithm
Solution: Optimal
Speed: Usually Slow
Guarantee: 100% Correct

------------------------------------------------------------
Approximation Algorithm

Solution: Near Optimal
Speed: Moderate
Guarantee: Performance Bound Exists

------------------------------------------------------------
Heuristic Algorithm

Solution: Good Enough
Speed: Fast
Guarantee: No Guarantee

------------------------------------------------------------
OPERATIONAL ALGORITHMS

Operational algorithms focus on completing a sequence of computational tasks rather than optimizing a specific objective function.
Algorithms designed primarily for processing and operational tasks.
Operational algorithms are created to carry out a set of steps or tasks efficiently, 
rather than finding the "best" solution according to some mathematical objective function.

Properties:
• Focus on execution
• Not necessarily optimization-based
• Often used in practical applications

------------------------------------------------------------
OPERATIONAL ALGORITHM EXAMPLE

ClustalW (Bioinformatics)

Purpose: Sequence Alignment
Goal: Perform biological sequence analysis efficiently.
Focus: Task completion rather than finding an optimal mathematical solution.

------------------------------------------------------------
TRAVELING SALESMAN PROBLEM (TSP)

TSP is a famous NP-Hard optimization problem.
Find the shortest route that visits every city exactly once and returns to the starting city.

------------------------------------------------------------
GREEDY APPROXIMATION FOR TSP

The following approximation approach can be used:
Step 1: Construct a Minimum Spanning Tree (MST).
Step 2: Duplicate the tree edges to create an Eulerian Graph.
Step 3: Find an Eulerian Cycle.
Step 4: Use shortcuts to transform the cycle into a Hamiltonian Cycle.

Result: Produces a route close to the optimal solution.
Time Complexity: O(n²)

2.4 CLASSIFICATION ACCORDING TO MAIN CONCEPT

Algorithms may also be classified by their problem-solving technique.

Main Categories:
• Simple Recursive Algorithm
• Divide-and-Conquer Algorithm
• Dynamic Programming Algorithm
• Backtracking Algorithm
• Greedy Algorithm
• Brute Force Algorithm
• Branch-and-Bound Algorithm

------------------------------------------------------------
SIMPLE RECURSIVE ALGORITHM

A recursive algorithm solves a problem by repeatedly solving smaller versions of the same problem.
A function calls itself until a base case is reached.

------------------------------------------------------------
CHARACTERISTICS OF RECURSION

• Solves a base case directly
• Solves a smaller subproblem
• Builds the final solution from smaller solutions

------------------------------------------------------------
RECURSION EXAMPLE

Counting Elements in a List

Algorithm:
1. If list is empty → Return 0
2. Remove first element
3. Count remaining elements
4. Add 1

------------------------------------------------------------
SEARCHING EXAMPLE

Check if a value exists in a list.

Steps:
1. If list is empty → Return False
2. If first element matches → Return True
3. Search remaining elements recursively

------------------------------------------------------------
DIVIDE-AND-CONQUER ALGORITHM

Divide-and-Conquer breaks a large problem into smaller subproblems.
Solve smaller subproblems and combine their answers.

------------------------------------------------------------
HOW DIVIDE-AND-CONQUER WORKS

Step 1: Divide the problem.
Step 2: Solve each subproblem.
Step 3: Combine the solutions.

------------------------------------------------------------
DIVIDE-AND-CONQUER STRUCTURE

Problem
   |
Divide
   |
Subproblems
   |
Solve
   |
Combine
   |
Final Solution

------------------------------------------------------------
QUICKSORT

Steps:
1. Partition the array.
2. Sort each partition recursively.
3. No major combine step required.

Time Complexity: O(n log n) Average Case

------------------------------------------------------------
MERGE SORT

Steps:
1. Split the array into halves.
2. Sort each half.
3. Merge sorted halves.

Time Complexity: O(n log n)

------------------------------------------------------------
ADVANTAGES

• Highly efficient
• Logarithmic recursion depth
• Suitable for large data sets

------------------------------------------------------------
DYNAMIC PROGRAMMING ALGORITHM

Dynamic Programming (DP) solves problems by storing solutions to previously solved subproblems.
A problem-solving technique that avoids repeated calculations.

------------------------------------------------------------
WHY DYNAMIC PROGRAMMING IS NEEDED

Problem: The same subproblems may be solved repeatedly.
Solution: Store previous results and reuse them.

------------------------------------------------------------
MEMOIZATION

Memoization means storing computed results for future reuse.
Benefit: Avoids unnecessary recalculations.

------------------------------------------------------------
DYNAMIC PROGRAMMING EXAMPLE

Fibonacci Sequence
Formula:
F(n) = F(n−1) + F(n−2)

Without DP: Many repeated calculations.
With DP: Each value is calculated once.

------------------------------------------------------------
ADVANTAGES

• Faster execution
• Eliminates duplicate computations
• Converts exponential solutions to polynomial or linear solutions

------------------------------------------------------------
OPTIMAL SUBSTRUCTURE

optimal solution contains optimal solutions to smaller subproblems.

Example:
Shortest Path Problems

------------------------------------------------------------
OVERLAPPING SUBPROBLEMS

The same subproblems are solved repeatedly.

Example:
Fibonacci Numbers

------------------------------------------------------------
APPLICATIONS OF DYNAMIC PROGRAMMING

• Knapsack Problem
• Fibonacci Numbers
• Sequence Alignment
• Viterbi Algorithm
• Shortest Path Problems

------------------------------------------------------------
BACKTRACKING ALGORITHM

Backtracking builds solutions step-by-step and abandons invalid paths immediately.
Explore a path and backtrack whenever a condition is violated.

------------------------------------------------------------
HOW BACKTRACKING WORKS

1. Choose an option.
2. Test validity.
3. Continue if valid.
4. Backtrack if invalid.

------------------------------------------------------------
N-QUEENS PROBLEM

Goal: Place N queens on a chessboard so that no queen attacks another queen.

Method:
• Place queen
• Check validity
• Continue
• Backtrack if necessary

------------------------------------------------------------
ADVANTAGES

• Avoids unnecessary exploration
• More efficient than Brute Force
• Quickly eliminates invalid solutions

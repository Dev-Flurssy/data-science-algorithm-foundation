DETERMINISTIC AND RANDOMIZED ALGORITHMS

Algorithms can be classified based on how they produce their results.

------------------------------------------------------------
DETERMINISTIC ALGORITHM

A deterministic algorithm always produces the same output for a given input.

Definition:
Given the same input, the algorithm follows the same steps and generates the same result every time.

Example:

Input:
5, 3, 2

Output:
2, 3, 5

If executed again:
Input:
5, 3, 2

Output:
2, 3, 5

Result:
The output never changes.

------------------------------------------------------------
PROPERTIES OF DETERMINISTIC ALGORITHMS

• Predictable behavior
• Same execution path every time
• Same output for the same input
• Easier to debug and test

Examples:
• Binary Search
• Merge Sort
• Insertion Sort
• Linear Search

------------------------------------------------------------
RANDOMIZED ALGORITHM

A randomized algorithm uses random choices during execution.

Definition:
The algorithm may follow different execution paths even when the input remains the same.

Example:

Input:
5, 3, 2

Run 1:
Chooses Path A

Run 2:
Chooses Path B

Run 3:
Chooses Path C

Result:
Execution differs each time.

------------------------------------------------------------
PROPERTIES OF RANDOMIZED ALGORITHMS

• Uses random decisions
• Different execution paths
• Often faster in practice
• Reduces worst-case situations

Advantages:
• Simpler design
• Better average performance
• Handles difficult inputs effectively

------------------------------------------------------------
DETERMINISTIC VS RANDOMIZED ALGORITHMS

Deterministic Algorithm

Input
  ↓
Fixed Steps
  ↓
Same Output

------------------------------------------------------------

Randomized Algorithm

Input
  ↓
Random Choice
  ↓
Different Execution Paths
  ↓
Output

------------------------------------------------------------

COMPARISON

Deterministic Algorithms:
• Predictable
• Same output every time
• Same execution steps

Randomized Algorithms:
• Unpredictable execution path
• Uses randomness
• May produce different outcomes

------------------------------------------------------------
TYPES OF RANDOMIZED ALGORITHMS

There are two major types:

• Monte Carlo Algorithms
• Las Vegas Algorithms

------------------------------------------------------------
MONTE CARLO ALGORITHMS

A Monte Carlo algorithm may produce an incorrect answer, but the probability of error is very small.

Properties:
• Faster execution
• Small chance of error
• High probability of correct results

Example:

Input:
Prime Number Test

Result:
The algorithm may occasionally be wrong.

------------------------------------------------------------
MONTE CARLO CHARACTERISTICS

Advantages:
• Extremely fast
• Efficient for large problems

Disadvantages:
• Result may not always be correct

------------------------------------------------------------
LAS VEGAS ALGORITHMS

A Las Vegas algorithm always produces the correct result.

Properties:
• Output is always correct
• Running time may vary
• Uses randomization internally

Example:

Randomized Quick Sort

Result:
Correctly sorted array every time.

------------------------------------------------------------
LAS VEGAS CHARACTERISTICS

Advantages:
• Guaranteed correct answer
• Benefits from randomization

Disadvantages:
• Runtime may be unpredictable

------------------------------------------------------------
MONTE CARLO VS LAS VEGAS

Monte Carlo

Output:
May be incorrect

Runtime:
Usually predictable

Goal:
Fast approximation

------------------------------------------------------------

Las Vegas

Output:
Always correct

Runtime:
May vary

Goal:
Correct solution

------------------------------------------------------------
WHY USE RANDOMIZED ALGORITHMS?

Problem:
Certain inputs create poor performance for deterministic algorithms.

Solution:
Introduce randomness.

Benefits:
• Avoid worst-case inputs
• Improve average performance
• Simplify implementation

------------------------------------------------------------
REAL-WORLD APPLICATIONS

Randomized Algorithms are used in:

• Artificial Intelligence
• Cryptography
• Network Routing
• Machine Learning
• Data Analysis

2.2 ONLINE VS OFFLINE ALGORITHMS

Algorithms can also be classified based on when input becomes available.

------------------------------------------------------------
ONLINE ALGORITHM

An online algorithm receives input gradually during execution.

Definition:
The algorithm must make decisions without knowing future inputs.

Characteristics:
• Future data is unknown
• Decisions are made immediately
• Cannot revise previous decisions easily

------------------------------------------------------------
ONLINE ALGORITHM EXAMPLE

Food Delivery System

Orders Arrive:

Time 1:
Order A

Time 2:
Order B

Time 3:
Order C

The system must decide immediately how to assign deliveries.

Problem:
Future orders are unknown.

------------------------------------------------------------
PROPERTIES OF ONLINE ALGORITHMS

• Handles real-time data
• Works with incomplete information
• Used in dynamic environments

Applications:
• GPS Navigation
• Stock Trading
• Operating Systems
• Network Routing

------------------------------------------------------------
OFFLINE ALGORITHM

An offline algorithm knows all inputs before execution begins.

Definition:
The complete data set is available before processing starts.

Characteristics:
• Full knowledge of inputs
• Can plan better solutions
• Often achieves optimal results

------------------------------------------------------------
OFFLINE ALGORITHM EXAMPLE

Exam Scores

Scores Available:

78
95
63
88
74

Since all data is available before processing begins, sorting can be optimized.

------------------------------------------------------------
ONLINE VS OFFLINE ALGORITHMS

Online Algorithm

Input:
Received gradually

Future Inputs:
Unknown

Decision:
Immediate

Applications:
• Navigation
• Scheduling
• Network Routing

------------------------------------------------------------

Offline Algorithm

Input:
Available from the start

Future Inputs:
Known

Decision:
Planned in advance

Applications:
• Batch Processing
• Sorting
• Data Analysis

------------------------------------------------------------
SKI RENTAL PROBLEM

The Ski Rental Problem is a classic example of an online algorithm problem.

Situation:

A skier has two choices:

• Rent skis daily
• Buy skis permanently

Unknown:
How many days the skier will continue skiing

------------------------------------------------------------
SKI RENTAL EXAMPLE

Rental Cost:
1 unit per day

Purchase Cost:
B units

Problem:
Should the skier continue renting or buy skis now?

Challenge:
The future number of skiing days is unknown.

------------------------------------------------------------
WHY ONLINE ALGORITHMS ARE DIFFICULT

Problem:
Future information is unavailable.

Result:
Decisions must be made with incomplete data.

Goal:
Make the best possible decision using available information.

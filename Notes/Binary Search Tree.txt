BINARY SEARCH TREE (BST)

A Binary Search Tree (BST) is a special type of Binary Tree where the data is stored in an organized manner.
This organization makes searching, insertion and deletion faster than a normal binary tree.

------------------------------------------------------------
WHY BINARY SEARCH TREES ARE NEEDED

In a normal Binary Tree:
Data can be stored anywhere.

Example:
       20
      /  \
    50    5

Searching becomes difficult.

----------------------------------
Solution:

Binary Search Tree
       20
      /  \
    10    25

Meaning: Data follows a specific order.

------------------------------------------------------------
DEFINITION OF BINARY SEARCH TREE

A Binary Search Tree is a Binary Tree in which every node 
satisfies the following conditions:
1. Left child contains smaller values.
2. Right child contains larger values.
3. Left and right subtrees are also BSTs.

------------------------------------------------------------
BST PROPERTY

For every node:
Left Subtree < Root < Right Subtree

Example
          20
         /  \
       10    25
      / \      \
     5  17      35

For Root 20:
10 < 20 < 25

For Node 10:
5 < 10 < 17

BST Rule is satisfied.

------------------------------------------------------------
EXAMPLE OF A BST

                20
              /    \
            10      25
           /  \       \
          5   17      35
         / \   /\     / \
        3  7 12 19  28 42
                     \    \
                     30   45

------------------------------------------------------------
ADVANTAGES OF BST

• Fast Searching
• Fast Insertion
• Fast Deletion
• Data remains ordered
• Inorder Traversal gives sorted output

------------------------------------------------------------
SEARCHING IN A BST

Purpose: Find a value in the tree.

----------------------------------
SEARCH RULE

If Value = Root
Found

If Value < Root
Go Left

If Value > Root
Go Right

Repeat until:
• Value Found
OR
• NULL Reached

----------------------------------
SEARCH EXAMPLE

Find 46
              45
             /  \
           35    50
          / \    / \
        30 38  48 55
               /
             47

46 > 45
Go Right

46 < 50
Go Left

46 < 48
Go Left

NULL Reached
Result:
46 Not Found

------------------------------------------------------------
SEARCH ADVANTAGE

Only one subtree is searched.
Similar to Binary Search in Arrays.

------------------------------------------------------------
MAXIMUM VALUE IN BST

Rule:
Follow right children continuously.
The rightmost node contains the maximum value.

Example
          20
         /  \
       10    50
             / \
           40  60

Maximum = 60

------------------------------------------------------------
MINIMUM VALUE IN BST

Rule:
Follow left children continuously.
The leftmost node contains the minimum value.

Example
          20
         /  \
       10    50
      /
     5

Minimum = 5

------------------------------------------------------------
DELETION IN BST

Three cases occur.

----------------------------------
CASE 1: DELETE LEAF NODE

Definition: Node has no children.

Before
      5
     /
    3

Delete 3

After
      5

Rule: Replace with NULL.

----------------------------------
CASE 2: DELETE NODE WITH ONE CHILD

Definition: Node has only one child.

Before
      10
        \
         20

Delete 10

After
      20

Rule: Promote the child.

------------------------------------------------------------
CASE 3: DELETE NODE WITH TWO CHILDREN

Definition: Node has both left and right child.

Before
         20
        /  \
      10    30

Delete 20

Rule:
1. Find Inorder Successor.
2. Replace node with successor.
3. Delete successor.

After
         30
        /
      10

Most important deletion case.

------------------------------------------------------------
SUCCESSOR

Definition: The smallest value greater than a given node.

----------------------------------
Rule 1

If node has a right subtree:
Successor = Minimum value in right subtree.

Example

        20
          \
           30
          /
        25

Successor of 20 = 25

----------------------------------
Rule 2

If no right subtree exists:
Move upward through right branches.
Parent obtained becomes successor.

------------------------------------------------------------
PREDECESSOR

Definition: Largest value smaller than the given node.

Rule:
Maximum value in left subtree.

Example
         20
        /
      10
        \
         15

Predecessor of 20 = 15

------------------------------------------------------------
IMPORTANT PROPERTY OF BST

Inorder Traversal of a BST always produces data in sorted order.

Example BST
        5
       / \
      3   7
     / \ / \
    1  4 6  8

Inorder Traversal
1 3 4 5 6 7 8
Sorted Order

------------------------------------------------------------
BST AS A SORTING METHOD

Idea:
1. Insert elements into BST.
2. Perform Inorder Traversal.

Example
Insert:
5 3 7 1 4 6 8

Inorder Output
1 3 4 5 6 7 8

Result:
Sorted Sequence Obtained

------------------------------------------------------------
SKEWED BST

Problem: If data is already sorted.

Example
Insert:
1 2 3 4 5

Result
1
 \
  2
   \
    3
     \
      4
       \
        5

This is called: Right Skewed BST
Problem: Tree height becomes very large.

----------------------------------
Search Path

To find 5:
1 → 2 → 3 → 4 → 5
Time Complexity: O(n)
Meaning: Performance becomes similar to a linked list.

------------------------------------------------------------
BALANCED BST ADVANTAGE

Smaller height.
Fewer comparisons.
Faster searching.

Average Search Time: O(log n)

------------------------------------------------------------
APPLICATIONS OF BST

• Searching Applications
• Database Indexing
• Dictionaries
• Symbol Tables
• Sorted Data Storage
• File Systems
• Compiler Design
• Data Sorting

------------------------------------------------------------
ADVANTAGES OF BST

• Data remains sorted.
• Fast searching.
• Fast insertion.
• Fast deletion.
• Inorder traversal gives sorted output.
• Dynamic structure.

------------------------------------------------------------
DISADVANTAGES OF BST

• Can become skewed.
• Performance may degrade to O(n).
• More complex than arrays.
• Requires extra memory for links.

------------------------------------------------------------
IMPORTANT POINTS

• BST is a Binary Tree with ordering rules.
• Left Subtree < Root < Right Subtree.
• Duplicate values are generally not allowed.
• Search uses only one subtree at a time.
• Maximum value is the rightmost node.
• Minimum value is the leftmost node.
• Deletion has three cases.
• Inorder traversal always gives sorted output.
• BST can be used for sorting.
• Skewed BST leads to poor performance.
• Balanced BST gives efficient searching.
